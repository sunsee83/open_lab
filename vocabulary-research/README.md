> **실제 학습 내용 추가(2026-11-16)**: [첫 10개 뜻·문법·예문 보기](reports/elementary-first-10-study.md) / [앱에서 읽을 JSON](data/elementary-first-10-study.json). 네이버 Oxford의 의미·품사·발음 구분을 직접 확인한 뒤 뜻 설명·예문을 새로 작성했습니다. 사전 원문 예문을 복제한 자료나 기출검증 완료 자료는 아닙니다.

## 목적

`moa_home/work/resource-development/program/english-word-card-generator/`의 **교육부 2022 개정 영어과 3,000개 원본** 중 초등 첫 10개 단어군만 대상으로, 네이버 영어사전의 **Oxford 전체 항목**을 브라우저에서 한 번에 조사하고 실제 소요 시간을 측정한다.

원본 목록을 대체하거나 학습 앱 데이터를 변경하지 않는다. 기존 `open_lab`의 reels-inspector 프로젝트와 별개이다.

## 수집 범위

- 영문 표제어, 미국/영국 발음기호
- Oxford 전 수준/품사의 개별 의미 항목, 수준 레이블, 뜻별 예문과 번역
- 네이버 상세 페이지의 숙어, 유의어 표시 영역(노출된 미리보기만)
- 출처, 확인 시각, 각 단어별 소요 시간, 실패/누락 상태
- 교육부 원본 괄호 관련형은 원문 그대로 보존하되, 별도 사전 확인 전 파생관계를 확정하지 않음

어원·철자 분석·형태소 분석·문법 정오·내신 기출·암기법은 **이 페이지의 DOM만으로 전부 검증할 수 없다.** 이 단계에서 추출 완료로 표시하지 않는다. `Oxford` 데이터의 외부 재배포 허가는 확인되지 않았다.

## 작업 방식

1. `words-elementary-pilot.json`에서 10개를 읽는다.
2. Playwright Chromium으로 `en.dict.naver.com`의 검색 → Oxford **All meaning** → 상세 페이지를 열고 품사별 모든 의미를 읽는다.
3. 빈 의미·표제어 불일치·상세 페이지 미접속을 실패로 기록한다(단어당 최대 2번 시도). 첫 단어에서 페이지 이동 타임아웃이 2회 계속되면 나머지는 `not_attempted`로 처리하여 10배의 불필요한 대기를 피한다.
4. 작업별 시간, 수준별 의미 수, 예문 수를 집계한다.
5. 사전 원문 뜻·예문은 공개 재배포하지 않는다. **직접 새로 쓴 학습 풀이·예문**은 출처/검증 상태를 명시해 공개 GitHub에 저장한다. Actions가 사전 원문을 수집해 자동 게재하는 것은 아니다.

이 10개는 **전체 연구 완료가 아니라 Oxford 사전의 1회 방문으로 확보 가능한 범위를 검증하는 실측 시험**이다. 추가 자료를 다른 사이트에서 조사하려면 별도 사용자 승인이 필요하다.

## 수동 실행

저장소 `sunsee83/open_lab` → `Actions` → `Elementary Vocabulary Research (10)` → `Run workflow`.

실행 결과는 GitHub Actions 요약과 `vocabulary-coverage-report` 아티팩트에서 확인한다. 10개 실행이 끝나야 3,000개 시간 추정치를 계산할 수 있다.
