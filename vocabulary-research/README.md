# 영어단어 원문 수집기 — 초등 10개 실험

## 목적과 원칙

- 교육부 원본 목록의 첫 10개 표제어군(괄호 안 관련형까지 개별 조회하면 13개)을 대상으로 네이버 영어사전의 Oxford 상세 화면을 조사합니다.
- **사전 화면의 `textContent`와 `outerHTML`을 그대로 수집하고, 수집 시점의 전체 렌더링 HTML도 보존합니다.** 뜻, 예문, 번역, 문법 설명을 AI가 새로 만들거나 바꾸지 않습니다. 이 HTML은 최초 서버 응답 원문이 아닌 브라우저가 렌더링한 DOM입니다.
- 표제어, 발음·활용형 표시 영역, 품사별 의미, 수준·용법 표시, 예문과 한글 번역, 숙어·유의어 표시 영역을 원문 조각으로 보존합니다. 원본의 공백·줄바꿈도 그대로 둡니다.
- 각 조회는 원본 목록의 단어군 ID, 실제 조회 표제어, 원본 링크 HTML, 상세 페이지 URL, 캡처 시각과 SHA-256 무결성 값을 함께 기록합니다.
- 수집된 사실과 수집기의 검증 결과(`captured_dom`, `needs_review`, `failed`, `not_attempted`)를 구분합니다. `captured_dom`도 **사이트에 존재하는 모든 항목을 빠짐없이 확보했다고 단정하지 않습니다.**

## 작동 방식

1. `words-elementary-pilot.json`에서 원본 단어 10개군을 읽고 관련형을 포함하여 13개 조회 대상으로 만듭니다.
2. GitHub Actions 실행기에서 Chromium을 이용해 검색 결과의 Oxford 상세 페이지를 방문하고, 가능한 예문 더보기 버튼을 펼칩니다.
3. DOM의 원본 텍스트와 HTML을 각 단어별 JSON에 넣습니다. 표시된 뜻 개수, 원본 표제어, 미확장 예문, 접근 실패를 검사합니다.
4. 저장된 JSON을 다시 읽어 SHA-256 값을 비교합니다. 확인할 수 없는 부분은 `needs_review`로 기록하고 임의로 보충하지 않습니다.
5. 작업 완료 시 요약에 조회별 상태와 수치만 출력합니다. **수치 요약은 조사 내용이 아니라 실행 진단입니다.**

## 공개 저장소와 결과 저장

- 공개 `sunsee83/open_lab`에는 **재사용할 수 있는 코드, 테스트, 입력 목록, 설명 문서만** 유지합니다. 이전 연습용 해설·예문·결과 파일은 현재 수집기에 쓰지 않습니다.
- 사전 원문과 조사 중간 결과는 기본적으로 Actions 실행기의 **임시 디렉터리**에만 저장되며 공개 커밋·아티팩트로 업로드하지 않습니다. **실행 종료 후에는 보존되지 않습니다.**
- 결과를 장기 보존하려면 사용자가 승인한 비공개 저장소 또는 개인 환경을 별도로 연결해야 합니다. `RAW_OUTPUT_DIR`은 실행기/개인 환경의 저장 경로를 바꾸는 옵션일 뿐 GitHub 저장을 뜻하지 않습니다.
- 사전 내용의 이용 및 재배포 권한은 별도로 확인해야 합니다. 다른 사이트의 자료 수집, 학습 앱 적용, 새 서버 또는 외부 저장소 생성은 이 워크플로에서 수행하지 않습니다.

## 실행 및 한계

GitHub `sunsee83/open_lab` → **Actions** → **Elementary Vocabulary Research (10)** → **Run workflow**. 수동 실행만 가능하고 `main`에 코드를 올려도 자동 실행되지 않습니다.

검증 명령: `npm run check` (`node --check` 및 로컬 테스트). 실제 조사: `npm run collect` (Playwright 의존성 설치 필요).

이전 실행에서는 GitHub Actions 실행기의 네이버 첫 화면 탐색이 타임아웃으로 실패했습니다. 이번 코드 변경은 **원문 충실성·무결성·결과 격리**를 위한 것이며, 해당 네트워크 접근 실패가 해결되었다고 주장하지 않습니다. 수집 대상 DOM 선택자는 사이트 변경 시 다시 검증해야 합니다.
