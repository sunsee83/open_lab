# Sheets 규칙

## 구조

- 파일: `유튜브다운로드sheet_v1`
- 한 영상 = 한 행
- A:AH = 도구 고정 열, 사용자 추가 열은 AH 오른쪽에만 추가
- 1행 = 헤더, 2행부터 데이터
- `안내` 시트는 저장 대상이 아님
- 기록 판정·중복 기준 = `영상 ID`(AC)
- `영상 URL` = AB, `채널 ID` = AD, `수집일시` = AG, `수정일시` = AH

## 저장

- 재수집 시 이번 실행에서 성공한 원본 필드만 갱신
- 관리정보는 사용자가 변경한 값만 갱신
- 명시적으로 지우지 않은 기존값은 유지
- `수집일시`는 최초값 유지, `수정일시`는 실제 변경 시 갱신
- 파일·시트·행 자동 삭제 없음
- 카테고리는 각 파일의 `안내` 시트 숨김 영역(C:D)에 저장

관리값: 활용 목적 `공부/자료조사/아이디어/보관`, 중요도 `1~5`, 상태 `미분석/분석중/완료/보류`.

## 제한

| 항목 | 제한 |
| --- | ---: |
| 연결 파일 | 10 |
| 데이터 시트/파일 | 10 |
| 기록/시트 | 2,000 |
| 경고 시작 | 1,800 |
| 카테고리/시트 | 30 |
| 셀 문자열 | 약 49,000자 |

2,000행 도달 시 신규 추가만 차단하고 기존 기록 수정은 허용합니다. 49,000자를 넘는 문자열은 잘라 `[일부 내용 생략]`을 표시합니다. 로컬 TXT/JSON에는 이 제한을 적용하지 않습니다.
