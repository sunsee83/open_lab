# Instagram RI Bookmarklet

현재 활성 버전: **v0.9.9**

## 설치 / 업데이트
1. bookmarklet-url.txt 전체를 북마크 주소에 넣는다.
2. Instagram 모바일 웹에서 실행한다.
3. 이후 RI 관리 → 업데이트로 본체를 갱신한다.

이전 사용자는 이번에 북마크 주소를 **한 번 교체**해야 한다. 기존 북마크 문자열은 본체 업데이트만으로 영구 변경할 수 없다. 새 본체 실행 중에는 안전한 업데이트 함수를 사용한다.

## 수정 내용
- 자체 화면 변경으로 생기던 갱신 반복 제거
- 동일 버전 재실행 정리와 종료 후 작업 취소
- 화면 전환 응답 역전 / 이전 저장 대상 잔존 방지
- API 응답·identity 검증과 fallback
- 정확한 API 수치 보호, 다른 콘텐츠 수치 혼입 차단
- 캐시 10분 만료, 요청 공유·동시성 제한·실패 cooldown
- 실제 조회수 관측만 history 기록, 과거 오염 기록 제외
- 게시일 기준 최근 게시물로 계정대비 계산
- 일괄 저장 부분 실패 표시, 저장창 선요청
- MP4/M4A 트랙과 이미지 형식 검증
- 업데이트 발신자 검증과 정상 실행 후 캐시 교체

## 화면 / 연구
공통 8지표: 조회수·좋아요·댓글·재게시 / ER·24h·계정대비·게시일.

게시일만 있어도 표시하며 없는 수치는 추정하지 않는다. 상세 탭은 요약 / 콘텐츠 / 댓글 / 분석 / 미디어다.

- 콘텐츠: 본문·해시태그·언급, STT/OCR 실행과 결과 가져오기
- 댓글: 원문·답글·규칙 기반 분류와 실제 수집 범위
- 분석: 첫 문장·CTA·숫자·가격 추출과 근거
- 데이터: JSON/CSV 내보내기
- 미디어: 영상·음원·표지/첫 프레임·사진·슬라이드 저장

STT/OCR은 별도 창에서 **기기 안에서** 처리한다. 첫 실행에 공개 모델 다운로드가 필요하며 원본을 분석 서버로 보내지 않는다. 음성은 최대 180초, 영상 OCR은 2초 간격 최대 60프레임이다. 캐러셀 OCR 기본 대상은 첫 항목이다. 모델 결과와 처리 범위를 표시하며 SRT/VTT/TXT/JSON 가져오기도 지원한다.

## 검증 / 제한
저장소 루트에서 `node --test tests/instagram-bookmarklet.test.cjs`.

Instagram 비공개 API 응답, 브라우저 저장 API, 기기 메모리, 모델 다운로드 상태에 따라 가용 기능이 달라진다. 실패를 성공으로 표시하지 않는다.

실제 로그인 세션과 Android Edge에서의 다운로드·자동 인식 검증은 별도이며 모의 테스트를 실기기 PASS로 취급하지 않는다.
