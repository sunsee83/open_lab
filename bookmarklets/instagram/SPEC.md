# Instagram RI — Specification

현재 기준: **v0.9.9**

## 화면과 파일
- 리서치 모드에서는 실제 정보와 비교 가능성을 우선한다. Instagram native UI와 Grid 크기는 유지한다.
- Grid / Reel / Feed / 간단 보기 / 상세 5탭의 공통 8지표: 조회수·좋아요·댓글·재게시 / ER·24h·계정대비·게시일.
- 게시일만 있어도 표시한다. 미확인 값을 0으로 만들지 않는다. Grid는 빈 슬롯, 상세는 확인중으로 표시한다.
- 활성 파일은 README.md, SPEC.md, bookmarklet-url.txt, bridge-stable.svg, current.js 다섯 개다.
- 회귀 테스트는 루트 tests/ 아래에 둔다. reels-inspector/**는 읽기 전용이다.

## 실행과 수집
- 같은 버전도 재실행 전 종료하며, 종료 시 요청·예약 프레임·타이머·분석 창을 정리한다.
- RI 자체 DOM 변경은 재스캔을 유발하지 않는다. 같은 값으로 DOM을 다시 쓰지 않는다.
- shortcode를 identity로 사용한다. 이전 화면의 응답은 현재 콘텐츠를 덮지 않는다.
- API 응답은 wrapper 해제 후 identity와 미디어 구조를 검증한다. 빈 응답이나 다른 콘텐츠는 fallback한다.
- API 요청 동시성은 2개, 같은 콘텐츠의 진행 중 요청은 공유한다. 실패 후 최소 30초간 재시도를 제한한다.
- 메모리 캐시와 API 확인 유효기간은 10분이며 화면 주변 콘텐츠를 주기적으로 갱신한다.
- native 수집은 RI와 다른 콘텐츠를 제외하며 직접 연결된 숫자만 읽는다. 정확한 API 값을 축약 화면 값으로 덮지 않는다.
- 새 조회수를 실제로 관측했을 때만 history에 기록한다. 이전 버전의 검증되지 않은 history는 24h 계산에서 제외한다.
- ER은 조회수 > 0이고 좋아요·댓글·재게시가 모두 확인됐을 때 계산한다.
- 24h는 최신 실제 관측 시각 기준 18~32시간 전의 검증된 snapshot 중 24시간에 가장 가까운 기록과 비교한다. 현재 관측이 만료되거나 조회수가 감소하면 표시하지 않는다.
- 계정대비는 동일 계정, 현재 콘텐츠 제외, 게시일 기준 최근 최대 20개·최소 5개의 조회수 중앙값 대비 배수다.
- 저장공간 오류를 숨기지 않으며 JSON/CSV 내보내기를 제공한다.

## 저장
- 영상·음원·표지/첫 프레임·사진·캐러셀 전체 개별 저장을 지원한다.
- 기본 다운로드·지정 폴더·매번 선택을 지원한다. 저장창/폴더 권한은 네트워크 대기 전에 요청한다.
- 일괄 저장의 매번 선택은 전용 폴더를 먼저 선택한다.
- MP4 컨테이너·영상 트랙·오디오 트랙 확인 후 소리 포함 영상으로 저장한다. 음원은 오디오 트랙이 있는 M4A로 검증한다.
- 표지가 없으면 정확한 0.000초 첫 표시 프레임을 생성한다. MediaRecorder/실시간 녹화 fallback은 사용하지 않는다.
- 이미지 확장자는 실제 형식과 일치시킨다. 일괄 저장은 부분 실패와 전체 실패를 성공으로 표시하지 않는다.
- 취소는 정상 취소로 처리하며 오류 알림을 띄우지 않는다.

## 연구 기능
- 본문·해시태그·언급을 API 원본에서 추출한다.
- 댓글 버튼을 누르면 API가 허용한 댓글·답글을 페이지 단위로 수집한다. 범위·한도·누락을 표시한다.
- 댓글 분류와 첫 문장·CTA·숫자·가격은 규칙 기반 추출이며 근거 원문을 함께 보여준다.
- STT/OCR은 명시적 실행 시 별도 분석 창에서 기기 내 처리한다. 원본을 분석 서버에 업로드하지 않는다.
- STT: 고정 버전 Transformers.js와 Whisper tiny 다국어 모델, 최대 180초.
- OCR: 고정 버전 Tesseract.js, 한국어+영어. 영상은 2초 간격 최대 60프레임, 이미지 1장. 시간·위치·문구를 보관한다.
- 캐러셀 OCR 기본 대상은 첫 항목이며 이를 화면에 표시한다.
- 첫 실행 모델 다운로드와 기기 성능이 필요하다. 모델 추정값과 샘플링 범위를 실제 전체 인식으로 표시하지 않는다.
- SRT/VTT/TXT/JSON 결과 가져오기를 제공한다. 시간이 없는 텍스트에 임의 시간을 만들지 않는다.
- 브라우저/CSP/메모리/팝업/모델 다운로드 제한 시 원인을 표시한다.

## 업데이트
- 인증키·비밀번호·세션·token을 코드/공개 저장소에 저장하지 않는다.
- bridge는 고정 commit, 본체는 main의 정확한 commit SHA에서 가져온다.
- 메시지 origin·source·암호학적 난수 token·type·크기·구조를 검사한다.
- bridge는 정확한 Instagram origin으로만 응답한다.
- 본체 준비 확인 후 캐시를 교체한다. 실패 시 복구 버튼과 이전 정상 캐시를 유지한다.
- v0.9.9 최초 전환 시 북마크 URL을 한 번 교체한다. 이후 기능 업데이트는 RI 업데이트를 사용한다.

## 검증
- Node 회귀 테스트로 identity·수치·캐시·저장·loader/bridge·연구 결과 처리를 검사한다.
- 실제 Instagram/Android Edge 확인 전 실기기 PASS로 기록하지 않는다.
